# Нативный ReStarter64

Win32/C++17, MSVC v143 x64, статическая CRT. Сборка и статус передачи:
[основной README](../README.md). Полный контракт и список отличий:
[карта миграции](../docs/native64-migration.md).

`app.cpp` — главное окно, графика/темы, DXGI и навигация;
`settings.inl` — настройки, отложенные поля, пресеты и HUD;
`information.inl` — встроенная информация и лицензии;
`storage.cpp`/`profile.inl` — файлы, XML, INI и запуск Engine64;
`Generate-Schema.ps1` — полная схема из OwnedRendererSchema64.cs во время сборки.

Нативная x86-цель заменена x64. Исходный C# сохранён.
Первая сборка устарела после исправления исходника; повторная не разрешена BRIEF.

Сборка build-native.ps1 теперь использует ReStarter64.vcxproj: MSBuild отслеживает
C++, заголовки и ресурсы; obj хранятся рядом с выбранным OutputPath.
Generate-Schema.ps1 сохраняет schema.cpp, если текст схемы не изменился.
Повторная неизменённая сборка не компилирует и не перелинковывает EXE.
