# ReStarter на C++

Редакция R2 переносит одинаковое с EIStarter R8 окно выбора модов в
`mod-picker.inl`: размер по числу строк с учётом DPI, компактный заголовок,
золотая отметка текущего мода, версия справа. Поиск с иконкой показывается
для списка длиннее пяти модов, прокрутка — только при переполнении. Фильтрация
обновляет строки и их индексы вместе; щелчок по пустому месту не выбирает мод.
Сохранены стрелки/Enter/Esc, добавлена буферизация строк и композиция окна.
Результат на реальном экране оценивает владелец.

Самостоятельный Win32/x86-стартер EIRebuild без .NET и установки Visual C++
Redistributable. Целевая система — Windows 7 SP1 и новее; MSVC v142,
статическая CRT `/MT`, подсистема Windows 6.01. Работа на реальной Windows 7
пока не подтверждена. Используются системные Win32, GDI+, MSXML6 и Crypt32.

Интерфейс перенесён из native EIStarter R7: главный экран, светлая и тёмная
темы, выбор и карточка мода, разделы настроек с прежними иконками,
компактные кнопки, группы камеры, буферизация кнопок и прокручиваемой панели.
Иконка, фон и переводы берутся из собственного C#-проекта ReStarter.
Подсказка F10 и кнопка «Авто» сохранены. Для новой конфигурации «Авто» выбрано
по умолчанию; сохраняется штатный флаг `[setup] first_run_done=false`.
Ручной пресет завершает автоподбор. Режим окна, VSync, лимит FPS и прочие
параметры вне пресетов при выборе «Авто» сохраняются.

## Запуск и профиль

Запускается только `Engine/EIRebuild.exe`, с рабочей папкой `Engine` и
аргументом `-profile "<абсолютный путь>/restarter-settings.xml"`.
Модификация обязательна. Отдельная RDDraw.dll не требуется: рендер встроен
в актуальный EIRebuild. После успешного запуска игры стартер закрывается.

Собственные файлы: `restarter.config`, `restarter-settings.xml`,
`restarter-defaults.xml`, `Engine/rddraw.ini`. Начальные значения встроены
в EXE. Существующие пользовательские файлы сохраняются. Обычная работа не
читает и не записывает реестр EI_Starter/Nival либо файлы старого стартера.
Мьютекс — `ReStarterSharp`, служебная папка — `%LOCALAPPDATA%/ReStarter`.

Если собственного XML-профиля ещё нет, однократно импортируется
`portable-settings.xml`, либо read-only снимок старого EI_Starter.
При отсутствии старых значений используются собственные defaults.
Отсутствующий `restarter.config` может получить настройки из `starter.config`
без ExeName, отсутствующий `rddraw.ini` — копию `eid3d11.ini`.
Источники импорта не изменяются; собственный профиль публикуется последним.

Изменения XML и INI сохраняются атомарно; прежний вариант остаётся в
`.native-backup`. Сохраняются посторонние значения, XML-метаданные и
неизменённые строки INI. Перед записью проверяется конфликт с открытым
снимком. Настройки меняются при закрытом EIRebuild. Режим совместимости,
WINEDEBUG и временный реестр оригинального game.exe сюда не перенесены.
Кнопка «Сайт» открывает https://vk.ru/ei_dejavu.

## Сборка и комплект

Из корня репозитория: `./build-native.ps1 -OutputPath <папка>`.
Нужны MSVC 14.29.30133 и Windows SDK 10.0.22621.0. PowerShell нужен только
разработчику. `Generate-Schema.ps1` переносит существующую схему настроек
рендера и переводы в C++ во время сборки. Выход: `ReStarter.exe` и
`background.jpg`. Старые System.*.dll и ReStarter.exe.config не нужны.

Это отдельный кандидат; C#-проект сохранён. Без запуска приложения или игры
нельзя подтвердить визуальное совпадение, прокрутку, масштабирование,
Windows 7/Wine/Proton и полный цикл запуска EIRebuild. Системный DPI
сохраняет модель native EIStarter; динамического PerMonitorV2 здесь нет.
Тесты, приложение и игра исполнителем не запускались. Установка и push
в эту работу не входят.
