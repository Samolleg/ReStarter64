# Проверки ReStarter

Сначала `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1`.

Профиль, импорт, интерфейсные привязки без показа окон и конфигурация рендера:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/Run-ProfileCheck.ps1 -EvidenceDirectory <приватный-каталог> -LegacyRoot <корень-с-копиями-старых-файлов>
```

Входы: `portable-settings.xml`, `starter.config`, `Engine/eid3d11.ini`. Тест
копирует их во временный каталог, работает с точной Release-сборкой и оставляет
там результаты для исследования. Оригиналы не меняет. Вместо реестра передаёт
запрещающий callback; отдельный сценарий проверяет импорт из предоставленного
callback один раз. Настоящий реестр не вызывается.

Проверяются все типы профиля, все привязки опций, атомарная публикация и отказ
записи, сохранение чужих значений/метаданных, конфликт изменений, staging и
сохранение defaults, rollback и конфликт `rddraw.ini`, подготовка команды
запуска без создания процесса и привязка выбранного мода. Заглушки EXE/DLL
создаются только в тестовом каталоге, никогда не исполняются и не загружаются.

Показ реального окна ReStarter и скриншоты выполняются отдельно с разрешением
задачи. Игра и старый EIStarter для этих тестов не запускаются.
