# Разрешение в ReStarter64

Настройки → Графика → Экран и сглаживание: «Разрешение окна».
Поле принимает свой размер, например 1280x720. В списке доступны режимы основного монитора Windows и «Автоматически (по монитору)».
Сохраняются graphics.window_width/window_height в Config64/rddraw.ini; автоматический размер — 0/0.
Существующий нестандартный размер сохраняется отдельным пунктом. Кнопка Отмена не записывает настройки.
Это размер оконного режима авторского рендера. Полный экран без рамки всегда имеет разрешение монитора;
для снижения нагрузки в нём используются масштаб рендера и апскейлер.
