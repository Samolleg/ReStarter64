# Иконка приложения

Синий драконий знак создан инструментом ImageGen на основе изображения,
предоставленного владельцем проекта для замены иконки стартера. Сохранены
голова, изогнутое тело и хвост металлического дракона с синим свечением.
По уточнению владельца центральная звезда, руны и прямые элементы монограммы
убраны; внутри силуэта оставлено прозрачное пространство.
Это адаптация изображения, а не неизменённый оригинал.

Редактируемый исходный PNG: `native/resources/starter-icon.png`, 1254 × 1254 RGBA,
сохранён байт в байт из результата генерации. `native/resources/favicon.ico`
содержит семь RGBA-размеров: 16, 24, 32, 48, 64, 128 и 256 пикселей. Конвертация
формата выполнена Pillow с сохранением внешнего вида и прозрачности.

MSBuild использует ICO как ApplicationIcon для Windows и Wine. Та же иконка
встроена в managed-ресурс `EIStarter.AppIcon`; LauncherTheme применяет её к
главному окну, настройкам и информационным окнам. Внешние файлы иконки при
запуске не требуются. Фон главного окна задаётся отдельно файлом background.jpg в формате JPEG.

Иконки четырёх разделов рисуются SettingsSectionButton: монитор с графиком,
группа игроков, камера и папка. Они сохраняют текстовые подписи, доступность,
подсветку выбранного раздела и цвета обеих тем, масштабируются по DPI.
