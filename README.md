# Evilauncher

Лаунчер, предназначенный для настройки и запуска игры "Проклятые земли" студии Nival.

Проект является духовным наследником EIStarter от GipatRu (https://www.gipath.org/forum/thread-2784.html).

# Ключевые возможности

Настройка всех ключевых параметров игры - пути к файлам, настройки графики, камеры

Поддержка тем оформления - каждый мод может показать собственный фасад

Поддержка переводов - локализация интерфейса программы

QoL фичи - информация о моде, версии аддона и т.д.

# Технические детали

C# / Windows Forms, .NET Framework 4.7.2. Из одного проекта собираются обычный
`EIStarter.exe` для Windows и отдельный `EIStarter-Wine.exe` для запуска через
Wine. Wine-версия также является приложением Windows, а не нативным приложением Linux.

Для сборки нужны Visual Studio Build Tools с MSBuild, пакет разработки .NET Framework
4.7.2 и восстановление NuGet-пакетов. Обычная Release-сборка: `build.ps1`.
Команда сборки Wine-версии приведена в [standalone/WINE.md](standalone/WINE.md).
Проверки без запуска игры описаны в [tests/README.md](tests/README.md).
Настройки нового рендера и подсказка F10 описаны в [docs/owned-renderer-settings.md](docs/owned-renderer-settings.md).

# Сторонние компоненты

ILMerge - (https://github.com/dotnet/ILMerge) историческая утилита проекта.
Текущий `build.ps1` отключает её post-build шаг; зависимости распространяются
рядом с EXE.


В репозитории находятся исходники стартера, локализация, фоновое изображение и
шрифт интерфейса. Файлы самой игры, мода и `addon.dll` сюда не входят;
автономный комплект игры готовится отдельно.
